# Security policy

## Reporting a vulnerability

Please report security issues **privately**, not in a public issue:

1. Open the [Security tab](https://github.com/zeeplabs/zeep-hive-releases/security) of this repository.
2. Click **Report a vulnerability** and describe the problem, the affected version and how to reproduce it.

Only the maintainers can see the report. We will reply in the advisory thread.

**Never include tokens, SSH keys, API keys or other secrets** in a report, and check terminal output for them before pasting it.

## Scope

- The Hive app for macOS (the signed DMG published in this repository's Releases).
- The update feed (`https://hive.zeeplabs.com.br/appcast.xml`) and the update process.
- The website at `https://hive.zeeplabs.com.br`.

## Supported versions

Fixes ship in a new release. Hive checks for updates and installs them after you allow it, so the latest release is the one that receives security fixes.
